Como Publicar no GitHub Pages Gratuitamente
1

Crie um Repositório no GitHub

Acesse o GitHub no seu computador ou no navegador do iPhone, clique em New Repository, dê o nome de viral-hub e marque como Public.

2

Adicione o Arquivo HTML

Dentro do repositório criado, clique em Add file > Create new file. Dê o nome do arquivo exatamente como index.html e cole este código completo dentro dele. Em seguida, clique em Commit changes.

3

Ative o GitHub Pages

Vá na aba Settings do repositório, clique em Pages no menu lateral. Em Build and deployment, selecione a Branch main e clique em Save.

4

Pronto! Acesse pelo iPhone

Em cerca de 2 minutos, seu site estará online no link https://seuu-usuario.github.io/viral-hub. Abra no Safari do iPhone, clique no botão de compartilhar e selecione "Adicionar à Tela de Início" para transformá-lo em um App!
